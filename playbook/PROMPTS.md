# PROMPTS — 시험 중 이 한 장만 위에서 아래로 (붙이는 글은 ▶ 상자 안뿐)

창은 셋뿐이다. **[창 1] Codex**(`codex`를 켜고 `›` 입력칸에 붙인다) · **[창 2] 터미널**(bash `$`에 그대로 친다) · **[창 3] 서버**(서버 하나만 띄워 둔다). 병렬은 없다 — 창 1에서 하나가 끝나면 다음을 붙인다.

▶ 표시 아래 ``` 상자 안만 복사해 붙인다. 상자 밖 글은 읽기만 한다.
상자 안 **〔 〕**는 내가 **과제의 말**로 바꿔 채운다 — README의 단어, 담당자가 쓴 단어, 숫자. 이 칸이 내 이해와 판단을 남기는 자리라 비워 두거나 일반어로 메우지 않는다. **〔A / B〕**는 하나만 남긴다. `{ }`는 Codex가 채우니 그대로 둔다.
붙인 글 앞에 `[200~`·`^[[200~`가 보이면 Codex가 아니라 bash에 붙인 것이다 → Ctrl+C → `codex` → `›` 뜬 뒤 다시 붙인다. Codex 입력칸에서 `[Pasted Content … chars]`로 접혀 보이는 것은 정상 — Enter.
첫 줄 `$이름`이 안 먹으면(보고에 "이번 목적:"이 없다) 이후 모든 상자의 첫 줄을 `.agents/skills/이름/SKILL.md 절차대로:`로 바꿔 붙인다.
Codex 보고는 화면과 같은 전문이 `out/reports/NN_명령.md`에도 남는다 — 화면이 지나갔으면 에디터로 연다.

# 구민 체육센터 강습 신청 서비스 (모의 과제 — 하네스 시험용 가상 도메인)

## 배경
체육센터 운영팀은 분기마다 강습 신청을 전화와 종이 대장으로 받습니다. 지금의 처리 순서는 아래와 같습니다.

```text
1. 전화 접수
2. 종이 대장에 적기
- 마감 3일 전 전화 확인
```

제공 데이터의 열 설명은 [데이터 설명](data/README.md)을 보세요.

## 운영 규칙
- 강습 한 반의 정원은 30명이며 대기자는 최대 5명까지 받습니다.
- 한 회원은 같은 분기에 강습을 3개까지 신청할 수 있습니다.
- 신청 마감은 개강 2일 전 18시입니다.
- 정원이 찬 반에 신청하면 대기 순번을 부여해야 합니다.
- 일정은 센터가 준 시간표를 그대로 씁니다.

## 요구사항
1. **회원 로그인** — 운영자와 회원 두 역할로 서비스 안에서 로그인합니다.
   - 채점자가 두 역할로 각각 들어가 볼 수 있어야 합니다.
   - 신청 편의와 관련한 조건은 담당자에게 확인할 수 있습니다.
2. **강습 목록** — 회원은 분기별 강습과 남은 자리를 봅니다.
3. **신청·취소** — 회원은 강습을 신청하고 취소합니다.
4. **대기 승격** — 취소가 생기면 대기 1번을 신청자로 올립니다.
5. **운영자 화면** — 운영자는 반별 신청자와 대기자를 봅니다.
6. **내보내기** — `SLOT_SCHEMA.md` 형식의 JSON으로 반 배정 결과를 내보냅니다.
7. **배포 고려** — 설정값은 환경변수로 받고 `.env.example`을 포함합니다. 헬스체크 경로와 `Dockerfile`을 둡니다.
8. **실행 문서** — `HOW_TO_RUN.md`에 실행 방법과 데모 계정을 적습니다.

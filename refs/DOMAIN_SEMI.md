# DOMAIN_SEMI — 반도체 데이터가 나왔을 때 (S1 inventory를 읽고 S2 질문을 만드는 용도)

> 과제 데이터에 lot·wafer·die·eqp·bin·yield·step·recipe 같은 열이 보일 때만 연다. **회사·제품마다 용어와 기준이 다르다. 도메인 수치·Bin 뜻을 지어내지 않고 담당자에게 묻는다.** 더 깊은 참고가 필요하면 공개 저장소의 도메인 자료를 /tmp 아래로 clone해 읽고 LOG 차용 표에 출처를 남긴다.

## 단위 계층 (키 열을 고를 때)
- 생산: **Lot(웨이퍼 묶음, 보통 ≤25장) → Wafer(원판) → Die/Chip(좌표 x,y) **. Shot = 노광 한 번 영역(다이 여러 개).
- 공정: **Route/Flow(단계 순서) → Step/Operation → Recipe(조건 집합)**, 처리 주체 **EQP/Tool → Chamber**(같은 설비라도 챔버마다 특성이 다를 수 있다).
- 흔한 표: 공정 이력(lot_id+step 키, eqp·chamber·recipe·track_in/out) · 설비 센서(시계열, eqp·chamber·sensor·value) · 계측(wafer+site) · EDS 결과(wafer+die 좌표, bin, test_item) · 알람·정비 기록(eqp·시각·코드·텍스트).
- 먼저 확인: 키 열 고유성, 시간대, **결측의 뜻(0인지 미측정인지)**, 단위, **양품 Bin 정의**.

## 테스트·수율 용어
- **Bin**: 테스트 결과 분류 코드. 양품 Bin과 불량 유형 Bin, Hard Bin(최종)/Soft Bin(세부). **번호 뜻은 반드시 담당자 확인.**
- **Yield**: 범위를 꼭 확인 — Line Yield(웨이퍼 생존), Die/Probe Yield(EDS 양품률), Package/Final Yield, 누적 = 곱. 리페어 전후 수율도 구분.
- EDS = 웨이퍼 상태에서 다이별 전기 검사(Probe Card) 후 Bin 부여. 이후 패키징 → Final Test·Burn-in.
- Wafer Map 패턴: Center·Donut·Edge-Ring·Edge-Loc·Scratch·Random 등(공개 데이터 WM-811K 분류). 정상이 대부분이라 클래스 불균형이 심하다.
- 공정 제어: FDC(센서 이상 감지), SPC(관리도, 관리 한계 = 평균±3σ — **규격 한계 USL/LSL과 구분**), APC/R2R, PM(예방 정비, **직후 특성이 바뀌는 경우 많음**), Excursion(정상 범위 이탈), Cp/Cpk(1.33을 흔히 기준으로 쓰나 회사 기준 확인), OEE, Cycle Time/TAT, WIP.

## 질문 유형별 기본 접근 (판정·계산은 고정 코드로)
| 질문 | 접근 | 주의 |
|---|---|---|
| 수율이 왜 떨어졌나 | 기간 전후 비교 → 단계·설비·챔버별 불량률 비교(공통성 분석) → 차이 큰 후보 순위 | 표본 적은 설비의 극단값 → **불량률과 n을 함께** |
| 어떤 설비가 의심되나 | 설비별 불량률 vs 전체, 비율 신뢰구간·카이제곱 | 여러 설비 동시 비교 = 다중 비교 |
| 공정이 안정적인가 | 관리도(X-bar/R, I-MR), Western Electric 규칙(±3σ 밖 1점 / 3점 중 2점 2σ 밖 / 5점 중 4점 1σ 밖 / 8점 연속 같은 쪽) | 관리 한계 ≠ 규격 한계 |
| 센서 이상 감지 | 레시피·단계별로 나눠 요약(평균·최대·기울기) → z-score·IQR | 레시피 섞으면 거짓 경보 |
| 불량 예측 | 로트·웨이퍼 단위 특징 → 트리 모델 | **분할은 로트·시간 기준**(다이 무작위 분할 = 누수). 정확도보다 Recall·PR-AUC |
| 병목·Cycle Time | 단계별 대기·처리 시간 분포, WIP 추세 | 평균보다 **P50·P90** |
| 알람·정비 텍스트 | 코드별 빈도·추세 → 요약·분류 | 원문 근거를 함께 |

- 결론 문장 형식: **"[기간]에 [단계]의 [설비/챔버]에서 불량률이 [x%p] 높음 (n=…, 근거: out/…)"**. 상관과 인과를 구분하고 다음 확인 행동("해당 챔버 PM 이력 확인")을 붙인다.
- 담당자별 관심: 공정/설비 엔지니어 → 어느 설비·챔버·레시피가 문제인가 / 수율·품질 → Bin·패턴·공통성 / 생산관리 → WIP·병목·납기 / 테스트 → Bin 분포·리페어.

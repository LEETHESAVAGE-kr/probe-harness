# ENV_FACTS — 환경 사실 카드 (공식 안내 기준 · 안내가 바뀌면 RUN.md 머리만 고친다)

## 1. 구조
| 항목 | 내용 |
|---|---|
| 시작 | 별도 공지 없음 → **시작 시각에 내가 직접 '과제 시작'** 클릭(녹화 자동 시작). 늦게 시작해도 종료 시각은 같다 |
| 순서 | 과제 **최대 180분** → 문항 준비 대기(약 5분, 최대 10분) → 후속 서술형 **6문항 × 5분** |
| 서술형 | 제출물·작업 기록으로 문항 생성. **AI·복사붙여넣기 금지, 직접 타이핑**. 이전 문항 복귀 불가, 5분 지나면 자동 확정 |
| AI | 응시 환경의 **Codex만**. `codex` → `/status` → `/model`. 기본 추론 강도가 높아(xhigh) 단순 수정은 느림 → 문서 정리·단순 수정은 `/model`에서 낮춘다 |
| 작업 폴더 | **홈(~) 자체가 작업 폴더**이고 작업 공간 파일이 전부 수집된다 → 하네스는 `/tmp/harness`에 받는다 |
| 메신저 | 실환경에는 **업무 담당자(실무자 에이전트)만** 있다(안내에 적힌 메신저 구성만 전제). Codex는 그 대화를 못 본다 → 답은 내가 "기록만 해라"로 LOG에 옮긴다 |
| 서버 | `0.0.0.0` 바인딩, 포트 **1024 이상**(3000·8000). 왼쪽 Browser 도구에 PORT·경로 입력. 서버 터미널 탭 닫지 않기 |
| 에디터 | 자동 저장. AI·터미널이 같은 파일을 고치면 저장 충돌 → "외부 변경 불러오기"/"현재 내용으로 저장" 중 선택. "일시정지" 안내가 떠도 타이머는 계속 |
| 허용 | 공개 GitHub `git clone`·다운로드, 외부 코드 참고·일부 차용, 공개 Skill/MCP |
| 금지 | git push·외부 전송, 결과물 통째 대체, 다른 AI·개인 키, 외부 브라우저, 감독·보안 우회, Computer Use, sudo 우회 |
| 공개 유지 | 쓴 공개 저장소(probe-harness)는 **결과 발표까지 공개 상태 유지** |

## 2. 무엇이 채점되나
- 수집: 코딩 에이전트·담당자 에이전트 대화, 터미널 세션, AI 도구 설정, **git log·diff·테스트 결과**, 작업 공간 파일 전체, **토큰 사용량**(간접).
- 축(채점 화면 기준, 각 100점):
  - **기술** — 유지보수성, 요구 충족, 기능 정확성, 품질 위험, 제출물 완성도
  - **의도** — 목표 구체화, 재사용 가능한 작업 체계, 맥락 유지·의도 갱신, **검증 루프**, 문제·제약 정의, **분해·위임**
  - **인지** — 산출물 동작·리스크 예측, 구조 이해, **결정 근거 이해**
- 항목마다 충족/부분충족과 **증거 위치**가 남는다.

## 4. 제출 절차
1. 필수 파일 경로·"저장됨" 확인. 충돌 표시가 있으면 해결. `git status` 깨끗.
2. 상단 **"제출하고 문제풀기"** → 미리보기(**일부 파일만 보이는 것은 정상**).
3. **"제출물 확정하고 문제풀기"** → 확정 후 수정 불가.
4. 서술형 끝 → "답안 제출하고 마치기" → **"과제가 잘 제출됐어요" + 제출 ID·시각·파일 수·크기** 확인.
5. 서술형 화면에는 신고 버튼이 없다. 오류가 나면 문항 번호·시각을 적어 둔다.

## 5. 문제가 생기면
| 상황 | 대응 |
|---|---|
| 접속 장애·반복 오류·감독 연결 | 상단 "문제 신고": 유형, 시각, 단계, 직전 동작, 오류 문구(키·토큰은 적지 않기). 타이머는 안 멈춘다 |
| 감독 장치 끊김 | "감독 연결" → "연결 확인" → 끊긴 장치만 재연결 |
| 탭 닫힘·새로고침 | 같은 링크로 재입장 → 화면 공유·감독 연결 재연결(작업은 서버 기준으로 이어짐) |
| 한 영역만 멈춤 | "이 영역 다시 불러오기". 터미널은 "다시 연결" 또는 `+` |

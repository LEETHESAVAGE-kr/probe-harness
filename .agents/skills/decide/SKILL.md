고치는 파일: DECISIONS.md(D1~D6 슬롯 · 거부한 것) · LOG.md "AI 위임 vs 직접 검증" 고정 절 · LOG.md 본표 한 행. 그 밖은 읽기만 한다. 사람이 답하기 전에는 아무 파일도 쓰지 않는다.

> 사용자가 명령 뒤에 붙인 목적·범위·하지 마라·내 판단·확인 줄은 이 파일의 지시보다 우선한다(고치는 파일 범위와 "멈춰라"는 그대로). 보고 첫 줄에 "이번 목적: …"을 그 문장 그대로 옮기고, 붙인 줄이 없으면 리스크 칸에 "[목적 줄 없음]"이라고 적는다.

# $decide — 결정 고르기 (S5, A 탭)

## 근거로 읽을 것 (이것만)
PLAN(만들 것 · 한계 · 가정) · REQUIREMENTS · LOG(본표의 "기록만 해라" 행 · 설명 카드 · 담당자 대화) · DECISIONS · 코드의 `// [Dn]` 주석 · tests/ 이름의 `[Dn]` · out/. 조건·숫자는 out/ 파일에서만 가져오고 파일 이름을 붙인다. 근거 없는 숫자는 `[기록 없음]`.

## 1. 슬롯 표 — 보여 주기만
D1~D6과 '거부한 것' 각각 제목 한 줄(`### D1 단순 규칙 먼저` 등) 아래 표 하나:

| 칸 | 후보 |
|---|---|
| 결정 후보 A/B | A: … / B: … — 코드·PLAN·담당자 답(HH:MM)에서. 지금 코드가 고른 쪽을 A로 |
| 이유 후보 ①②③ | ① … ② … ③ … — 한 줄씩. 그중 하나는 "더 단순한 쪽이 4문장으로 설명되어서" 류 |
| 대안(더 단순 · 더 정교) | 더 단순: … / 더 정교: … (PLAN 한계의 '대안'이 있으면 그것) |
| 약점 | 어떤 조건이면 무엇이 얼마나 — 조건·숫자는 out/ 파일에서만(파일 이름), 없으면 `[기록 없음]` |
| 검증 | 테스트 이름(`[Dn]`) · out 파일 |

- 해당 없는 슬롯(코드·테스트에 그 `[Dn]`이 없고 README 요구도 없음)은 결정 후보 하나 "A: 해당 없음 — README 범위 밖", 이유 후보 ① "README에 그 요구가 없다" 하나.
- 거부한 것: 설명 카드의 '바로잡은 것'과 LOG 본표의 요구 밖 반응에서 행마다 무엇을 · 왜(요구 번호) · 대신을 A/B로. 기록이 없으면 "A: 거부 기록 없음" 하나 — 꾸며 내지 않는다.

## 2. 고정 절 초안 — 보여 주기만
LOG "AI 위임 vs 직접 검증" 표를 LOG 본표의 "기록만 해라" 행 · 설명 카드 · out/ 숫자에서 자동 편집해 `| # | 맡긴 것 | 내가 확인한 것 | 어떻게 | 숫자 |`로 보여 준다(행 번호를 붙인다). 행마다 출처(LOG 행 시각 · 카드 번호 · out 파일). 숫자 칸은 out/ 또는 "기록만 해라" 행에서만, 없으면 `[기록 없음]`. 사람이 하지 않은 확인을 만들어 넣지 않는다.

## 3. 번호로 답을 받는다 — 멈춘다
표 아래 마지막 줄에 그대로: "번호로 답해라: 예 D1-A②, D2-B①, 거부-A③, 고정 절 '맞다' 또는 '3번 빼라'". 그리고 멈춘다. 파일은 아직 쓰지 않는다.

## 4. 답을 받으면 — 적고 커밋
- DECISIONS 슬롯마다 결정 칸: `내 선택: A — 이유: ② <이유 후보 ② 문장>`. 사람이 번호 대신 이유를 한 줄 쳤으면 그 문장을 이유로 그대로. 대안·약점·검증 칸은 1의 표 그대로.
- 답에 없는 슬롯은 건드리지 않는다. 해당 없음 슬롯은 결정 칸에 `해당 없음 — README 범위 밖`.
- 거부한 것: 고른 행을 `| 무엇을 | 왜 | 대신 |` 표에.
- LOG 고정 절: 2의 표에서 사람이 뺀 행을 빼고 확정 표로(행 번호 열은 뺀다).
- LOG 본표 한 행: `| S5 | $decide 선택 D1-A② … (사람이 친 답 그대로) | 슬롯 표·고정 절 초안 | 내가 고른 것 n건 | 시각 |` — 시각은 date로.
- `[S 5/6] 결정·검증 기록` 으로 DECISIONS.md · LOG.md만 커밋하고 `git show --stat HEAD`를 붙인다.

## 하지 않는 것
사람 답 전에 파일 쓰기 / 근거 없는 숫자 / 고르지 않은 슬롯 채우기 / 이유 후보를 사람 대신 고르기 / 위 두 파일 밖 수정.
